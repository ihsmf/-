# AI MONEY — Инструкция по созданию сценариев Shorts (строго до 60 секунд)

**Канал:** AI MONEY  
**Ниша:** ИИ + деньги / финансы / будущее богатства  
**Формат:** Shorts / Reels / TikTok — **строго до 60 секунд**, вертикаль 9:16  
**Цель файла:** По этому шаблону генерировать **полностью готовые сценарии** шортсов, где прописано всё до секунды:

- голос, который **идеально ложится под каждый кадр**
- покадровый визуал
- точные действия пользователя (что снимать, что генерировать, что монтировать)
- субтитры
- звук и монтаж
- обязательный CTA в Telegram

Используй этот файл как **единый источник правды**. При генерации сценария строго следуй структуре, тону, визуальным правилам и чек-листам ниже.

**Канал:** AI MONEY  
**Три главные рубрики:**

### 🤖 ИИ и деньги
- ИИ меняет экономику
- ИИ против трейдеров
- Эксперименты с нейросетями

### 📉 Большие деньги

### 📈 Будущее
- Будущее крипты
- Будущее банков
- Как технологии изменят богатство

**Тон канала:**
- Уверенный, чуть эмоциональный, «умный друг, который уже разобрался»
- Без воды
- Много конкретных цифр, фактов, «твистов»
- Лёгкая драма и интрига
- Не менторский и не крикливый

**Целевая аудитория:**  
Люди 20–45 лет, интересующиеся деньгами, ИИ, инвестициями. Смотрят с телефона, часто без звука.

Ссылка всегда в описании + мягко в конце озвучки.

## 2. Жёсткая структура шортса (строго ≤ 60 секунд)

**Цель:** 45–58 секунд. Никогда не превышать 60.

Всегда используй эту структуру. Не отклоняйся.

### 0:00–0:07 — ХУК (удар)
- Самое сильное заявление / шокирующий факт / вопрос.
- **Запрещено** «Привет», «Сегодня расскажу», «В этом видео».
- Визуальный крючок обязателен (огромная цифра, красная стрелка, лицо + деньги, график в моменте).

### 0:07–0:40 — ОСНОВНАЯ ЧАСТЬ (мясо)
- 2–3 быстрых факта / цифры / мини-история.
- Каждый новый факт — новый визуальный удар.
- Максимальная плотность информации. Никакой воды.
- Всё должно укладываться в одну мысль, которую зритель запомнит.

### 0:40–0:55 — ТВИСТ / ВЫВОД
- Главный инсайт или неожиданный поворот.
- Что это значит для зрителя прямо сейчас.

### 0:55–1:00 — CTA
- Подписка + колокольчик (быстро).
- **Telegram** (обязательно): мягкая фраза про бота по золоту + «ссылка в описании».
- Можно добавить «пиши в комменты» если остаётся время.

**Правило плотности:** в 55–60 секунд нужно вместить максимум пользы и эмоции. Каждая секунда работает.

## 3. Озвучка (Voiceover) — СТРОГИЕ ПРАВИЛА

### Инструменты
1. **ElevenLabs** — единственный рекомендуемый вариант. Один и тот же голос на весь канал.
2. Запасной — Speechify.
3. Запрещены бесплатные роботизированные голоса.

### Характеристики
- Уверенный, живой, чуть эмоциональный.
- Темп: быстрый, но чёткий (примерно 150–160 слов в минуту).
- Короткие предложения. Разговорный язык.

### Главное правило: голос идеально ложится под каждый кадр

Озвучка больше **не пишется одним сплошным абзацем**.  
Теперь озвучка разбита **по кадрам**. Каждая фраза голоса точно соответствует своему таймкоду и визуалу.

**Почему так:**
- Монтаж становится в разы быстрее.
- Субтитры совпадают идеально.
- Нет «плавания» голоса относительно картинки.
- Зритель воспринимает информацию плотнее.

**Формат в сценарии:**
```
0:00–0:02
Голос: «Я дал пяти нейросетям по десять тысяч долларов.»
Визуал: ...
Действия пользователя: ...
```

Каждая фраза голоса — короткая, законченная, и **точно** укладывается в длительность кадра (1,5–3 секунды).

**Расчёт объёма:**
- Для 55–58 секунд цель — **140–155 слов** суммарно.
- Меньше 130 — слишком пусто.
- Больше 165 — будет торопиться.

## 4. Визуальный ряд — СТРОГИЕ ПРАВИЛА

### Главное правило
**Никаких ИИ-клипов / ИИ-видео.**  
Максимум — **ИИ-картинки** (статичные) + Ken Burns / zoom / pan.  
Всё остальное: скринкасты, архивные фото, motion-текст, zoom-punch, реальные скрины.

### ОБЯЗАТЕЛЬНО: записи экрана компьютера
В **каждом** шортсе должны быть **записи экрана** (скринкасты) с компьютера.  
Это не опция, а обязательный элемент. Без них ролик не считается готовым.

Что именно снимать:
- Диалоги с ChatGPT / Claude / Gemini (промпт + ответ)
- TradingView / графики (только демо-счета)
- Терминал, код, таблицы, Excel / Google Sheets
- Браузер с новостями, отчётами, сайтами компаний
- Любые реальные действия на экране, которые подтверждают слова голоса

Минимум: **3–6 фрагментов** записи экрана в одном шортсе (суммарно 12–25 секунд).  
Скринкасты — это то, что делает ролик «настоящим» и доверительным.

### Плотность
- Смена кадра каждые **1,5–3 секунды**.
- На 55–60 секунд — минимум **20–28 кадров**.
- Визуал всегда бьёт в конкретную фразу голоса.

### Разрешённые типы визуала

| Тип                        | Что использовать                              | Длительность | Обязательность |
|----------------------------|-----------------------------------------------|--------------|----------------|
| **Записи экрана**          | OBS / встроенная запись: ChatGPT, TradingView, терминал, таблицы, браузер | 2–4 сек | **ОБЯЗАТЕЛЬНО в каждом ролике** |
| Ключевые цифры             | Крупный текст + zoom-punch                    | 1,5–2,5 сек  | Часто |
| Графики / данные           | Скринкаст TradingView (только демо)           | 2–3 сек      | Часто |
| ИИ-эксперименты            | Запись экрана ChatGPT / Claude / Gemini       | 2–4 сек      | По теме |
| Люди / компании            | Архивные фото + Ken Burns                     | 2–3 сек      | По теме |
| Абстракции / атмосфера     | **ИИ-картинки** (Ideogram / Flux) + медленный zoom | 2–3 сек | Дополнительно |
| Переходы / акценты         | Motion-текст CapCut / Canva                   | 1,5–2 сек    | Часто |
| Финальный CTA              | Текст + QR / логотип Telegram                 | 3–5 сек      | Всегда |

## 5. Действия пользователя (обязательный блок в каждом сценарии)

В каждом кадре сценария теперь прописывается блок **«Действия пользователя»**.  
Это то, что ты делаешь руками, чтобы собрать ролик.

Примеры того, что должно быть указано:

- Снять скринкаст в OBS: открыть ChatGPT → вставить промпт → дождаться ответа → записать 8–12 секунд.
- Сгенерировать ИИ-картинку в Ideogram / Flux по такому-то промпту.
- В CapCut: наложить zoom-punch + whoosh на этот кадр.
- Подготовить motion-текст «ОДНА СЛИЛА ВСЁ» красным.
- Записать TradingView (демо-счёт) с нужным графиком.
- Сделать финальный экран с QR-кодом Telegram.

Без этого блока сценарий считается неполным.

---

## 6. Монтаж, звук, субтитры

- **Субтитры обязательны** (крупные, контрастные, 2–3 строки максимум). Они берутся почти дословно из фраз голоса каждого кадра.
- **Zoom-punch** на каждой важной цифре и твисте.
- Звуковые эффекты:
  - Кассовый аппарат / звон монет — на больших суммах
  - Whoosh — при смене кадра
  - Удар / hit — на твисте
- Музыка: низкий ambient / electronic, не перебивает голос.
- Переходы максимально резкие и динамичные.

В сценарии указывай ключевые звуки и места zoom-punch прямо в кадре.

2. Держать библиотеку готовых ИИ-картинок (робот + деньги, золото, графики, серверы и т.д.).
3. Использовать один шаблон CapCut для всех шортсов.
4. Один голос ElevenLabs на весь канал.
5. Батчить озвучку и скринкасты.

Цель: 1 шортс = 40–70 минут чистого времени.

## 9. Чек-лист перед выдачей сценария

- [ ] Длительность ≤ 60 секунд (цель 52–58)
- [ ] Хук в первые 5–7 секунд без «привет»
- [ ] Озвучка разбита **по кадрам** — каждая фраза идеально ложится под свой визуал
- [ ] Суммарный объём озвучки ≈ 140–155 слов
- [ ] Визуал прописан покадрово каждые 1,5–3 секунды
- [ ] В каждом кадре есть блок **«Действия пользователя»**
- [ ] **Нет ни одного ИИ-клипа / ИИ-видео** (только статичные ИИ-картинки + Ken Burns)
- [ ] **Есть записи экрана компьютера** (минимум 3–6 фрагментов: ChatGPT / TradingView / таблицы / браузер и т.д.)
- [ ] Есть твист / сильный вывод
- [ ] Есть обязательный CTA в Telegram (бот по золоту)
- [ ] Субтитры, звук и zoom-punch указаны
- [ ] Есть варианты названия и обложки
- [ ] В описании есть ссылка на Telegram
- [ ] В конце сценария есть «Полный текст озвучки» одним абзацем для удобного копирования в ElevenLabs

## 11. Дополнительные правила

- Всегда пиши сценарий **на русском**.
- Цифры максимально конкретные.
- Никакой воды. Каждая фраза должна бить.
- В конце озвучки **всегда** мягкий CTA в Telegram.
- Визуал должен быть плотным и «дорогим» на вид (даже если это просто хорошие картинки + motion).
- При сомнении — лучше чуть короче и ударнее, чем длиннее.
- **Самое важное:** голос и картинка синхронизированы идеально. Каждая фраза — под свой кадр. Никакого «голоса в пустоту».
